# 창과 Dock 적설: 구현 및 검증

## 구현 범위

- SnowCore: 화면 좌표·창 전후 순서, 높이 열 기반 적설, 입자와 고정 간격 중력 적분.
- 일반 창 상단과 접근성에서 관측한 실제 Dock에 동시에 눈이 쌓입니다.
  하단 Dock은 긴 위쪽 테두리, 좌·우 Dock은 짧은 실제 상단 모서리를 지지면으로 사용합니다.
- 느린 이동은 눈을 운반하고, 빠른 이동·리사이즈·창 사라짐은 눈을 입자로 방출합니다.
- 이탈 눈은 중력 낙하 후 아래 지지면에 다시 쌓일 수 있습니다.
- 화면 전체 클릭 통과 오버레이에서 전경 창 내부를 잘라 그립니다.
- 최소화는 일반 창 목록에서 사라지는 것으로 처리해 눈을 방출합니다.
  Spaces 전환·화면 연결 변경·잠자기는 장면을 지워 전체 창 이동을 fling으로 오인하지 않게 합니다.
- 화면 전체를 덮는 맨 앞 일반 창에서는 해당 화면의 눈을 숨깁니다.
- 눈 기능은 도시 기능과 독립적으로 켜고 끌 수 있습니다.
- Settings의 Snow on windows에서 강도·창/Dock 적설·최대 깊이·동작 정지·저전력을 설정합니다.
- 방향 화살표를 드래그하면 360도 방향과 속도를 미리 보고 놓을 때 저장합니다.
  화살표 길이와 속도 슬라이더는 0~180pt/s를 설정합니다. 방향 프리셋·초기화 및 접근성 회전 조절도 제공합니다.
- 좌표는 오른쪽 +X, 아래 +Y입니다. 강설은 방향에 맞는 위/아래/좌/우 경계에서 유입됩니다.
  대각선 이동, 부드러운 흔들림과 방향 전환, 파편의 짧은 이동 잔상을 표시합니다.
- 설정 벡터는 떨어져 나온 눈의 초기 속도·바람에도 적용됩니다. 창 이동 관성에 더해지며 중력은 아래 방향을 유지합니다.
  수평·상향 강설은 표현할 수 있지만 상단 적설에는 하향 성분이 필요합니다.
- 메뉴에서 눈 일시정지/재개와 전체 눈 지우기를 실행할 수 있습니다.
- 설정 스키마 v4. 기존 도시·로그인 설정을 보존하고 누락된 눈 필드에는 기본값을 적용합니다.
- 오픈소스 설계 참고와 출처는 THIRD_PARTY_NOTICES.md에 기록했습니다.

## 자원 및 제한

- 한 화면당 최대 입자 1,200개, 지지면 64개, 지지면당 높이 열 256개.
- 물리 고정 간격 1/60초, 큰 시간 간격은 0.25초까지만 처리합니다.
- 기본 렌더링 30Hz, 저전력 15Hz. 동작 줄이기는 새 강설·움직임을 멈추고 기존 적설을 유지합니다.
- 일반 창 목록은 직렬 worker에서 읽으며 겹치는 요청을 만들지 않습니다.
- CG 기하가 0.8초 이상 갱신되지 않으면 오버레이를 숨깁니다.
- 실제 Dock에 눈을 쌓으려면 접근성 승인이 필요합니다. 도시가 꺼져 있어도 Dock 기하 추적은 유지합니다.
- 측면 Dock의 수직 벽면 적설·불규칙 창 실루엣·정확한 모서리 반경은 이번 구현 범위가 아닙니다.
- 눈이 바닥 전체에 무한히 쌓이는 효과는 없습니다. 지지면 밖 입자는 화면을 벗어나면 제거합니다.
- 적층과 파편은 시각 효과이며 입자 방출 과정의 재료 부피를 정밀 보존하는 유체/분체 해석은 아닙니다.
- Stage Manager·Mission Control의 임시 변형은 실제 Mac 검증이 필요합니다.

## 실행한 자동 검증

방향 벡터 추가 후 Linux Swift 6.0.3에서 전체 XCTest debug 68개 및 release 68개 성공, 각 실패 0개.
이 중 기존 opt-in 데모 도우미 1개는 기본 실행에서 동작하지 않습니다.
눈 관련 테스트 37개는 강설→적설, swept 충돌, 전경 가림, 부분 노출, 느린/빠른 이동,
리사이즈·소멸·순간이동, 중력과 아래 창 재적층, Dock 확대, 설정 독립성,
동작 줄이기·정지·지우기, 장시간 저장량 상한, 프레임 간격 독립성,
NaN/무한대·중복/대형 입력, 여러 화면 좌표, 전체화면, 설정 이전과 백업 복구를 포함합니다.
벡터 조절 좌표·회전·길이 제한·극단값, 사방향 유입, 대각선 강설,
Dock/창 동시 적설, 창에서 떨어진 눈의 Dock 재적층, 방향 변경 중 중력과 프레임 독립성도 확인합니다.

Swift 소스 문법 파싱, 패키징/검증 스크립트 셸 문법, diff 공백 검사도 통과했습니다.
Linux는 macOS 앱·AppKit 렌더러·CG 창 조회를 빌드하거나 실행하지 않습니다.
macOS 전용 테스트는 아래 실행 절차에 포함되며, 이 환경에서는 미실행입니다.

## Mac 자동 검증 — 별도 Mac 필요

GUI 로그인 세션에서:

```bash
cd DockCity
bash scripts/verify-macos.sh
open 'build/Dock City.app'
```

네이티브 테스트는 눈 패널의 포커스/마우스 정책, CG 메타데이터 필터링,
렌더러 픽셀 생성·지우기, 반복 시작·종료 후 패널 숨김을 검사합니다.
하단/좌/우 Dock 관측값에서 실제 상단 지지면을 만드는 테스트도 추가했습니다.
전체 debug/release 테스트와 `.app` 패키징·서명 검증 후 수동 검증을 진행합니다.

## 실제 GUI 검증 — 미실행

1. 여러 앱의 일반 창을 열고 창 상단에서 적설이 늘어나는지 확인합니다.
2. 창을 천천히 움직이면 적설이 따라오고, 빠르게 이동/리사이즈하면 눈이 떨어지는지 확인합니다.
3. 위쪽 창을 닫거나 최소화한 뒤 파편이 아래 창에 다시 쌓이는지 확인합니다.
4. 앞 창이 뒤 창의 눈과 입자를 정확히 가리는지 확인합니다.
5. 접근성 승인 전에는 창 적설이 동작하고, 승인 후 하단 Dock에도 쌓이는지 확인합니다.
6. 도시를 끄고 눈만 켜도 하단 Dock 적설이 유지되는지 확인합니다.
7. Dock 숨김·측면 전환·권한 철회 시 오래된 Dock 지지면이 남지 않아야 합니다. 좌/우 Dock은 상단 모서리만 쌓여야 합니다.
8. 클릭·드래그·우클릭·닫기 버튼·메뉴가 기존대로 동작해야 합니다.
9. 음수 좌표 보조 화면, Retina 배율, 화면 연결·분리에서 좌표를 확인합니다.
10. Spaces·전체화면·잠자기·깨우기·Stage Manager·Mission Control에서 장식 잔상을 확인합니다.
11. 눈 일시정지·재개·지우기, 창/Dock 적설 개별 설정, 동작 정지·저전력을 확인합니다.
12. 앱 종료 시 패널이 없어지고, 재실행 시 설정이 복구되는지 확인합니다.
13. 화살표를 좌하·우하·수평·상향으로 드래그해 미리보기와 실제 이동 방향이 일치하는지 확인합니다.
14. 길이를 줄이거나 늘려 속도를 바꾸고, 중심으로 옮겨 새 강설을 멈춥니다. 아래로 재설정해 창/Dock 적설을 재확인합니다.
15. 화살표 방향을 바꾼 뒤 창을 움직여 파편이 관성·바람·중력에 따라 움직이는지 확인합니다.
16. 방향 프리셋·초기화·접근성 조절과 앱 재실행 후 벡터 복원을 확인합니다.

실제 Mac에서 위 항목을 확인하기 전에는 ‘모든 테스트 완료’나 네이티브 실행 성공으로 보고하지 않습니다.
